Progetto peludo by Simone Serafin, Alessio Pantarotto, Davide Trevisan

Il progetto risulta completo

Riguardo le scelte chiave:
- Abbiamo utilizato una funzione non ricorsiva per calcolare il minimio
- Abbiamo utilizato una classe Function per gestire le funzioni e gradienti

Riguardo le altre carrateristiche del progetto:
- Abbiamo aggiunto una classe Vector2 per facilitare il lavoro con punti e gradienti
- Function e' stata creata in modo da riuscire a comprendere la funzione da una stringa e calcolarne autonomamente il gradiente
- Abbiamo quindi un main che dopo aver richiesto gli input costruisce le 8 funzioni partendo dalla rappresentazione testuale di esse

Riguardo la divisione del lavoro:
- Simone Serafin: minimizer, vector2
- Alessio Pantarotto: main
- Davide Trevisan: function

Note aggiuntive:

- Siamo coscenti che il codice di function e piu complesso del necessario, sia rispetto all'uso che ne viene fatto nel nostro progetto, sia rispetto alla consegna richiesta
